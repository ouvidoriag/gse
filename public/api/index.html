Controle de Taxa (Rate Limit) & Cabeçalhos

Todas as respostas da API incluem cabeçalhos informando a sua cota disponível:

Cabeçalho HTTPDescrição
X-RateLimit-LimitCota máxima diária autorizada para esta chave (ex: 10000).
X-RateLimit-RemainingTotal de requisições ainda disponíveis para o dia corrente.
X-RateLimit-Reset-DayData do reset da cota diária (em UTC, à meia-noite).

Códigos de Retorno HTTP Padrão:

StatusSignificadoAção Recomendada
200 OKSucesso total na consulta.Processar o JSON retornado.
400 Bad RequestParâmetro ou filtro inválido.Verificar a documentação dos parâmetros.
401 UnauthorizedCabeçalho X-API-Key não informado.Enviar a chave correta no cabeçalho HTTP.
403 ForbiddenChave inexistente, suspensa ou revogada.Solicitar ativação da chave junto à administração.
429 Too Many RequestsLimite de requisições por minuto ou diário atingido.Aguardar o reset ou solicitar ampliação de cota.

❓ Perguntas Frequentes (FAQ)

Como consigo minha Chave de API?

Você pode gerar sua chave diretamente nesta página através do botão "Solicitar / Gerar Chave de API" acima. Ela é permanente, não expira e já fica liberada para conectar como desenvolvedor/administrador instantaneamente.

Com que frequência os dados são atualizados?

Os dados são atualizados em tempo real. Assim que um serviço da Carta de Serviços ou um equipamento do SIGEM é modificado no painel da Prefeitura, a alteração reflete na API instantaneamente.

As chaves expiram? Como revogar?

As chaves geradas nunca expiram. Para revogar o acesso de qualquer desenvolvedor ou sistema, basta localizá-la na tabela "Chaves de API Ativas" acima e clicar no botão vermelho Excluir.
