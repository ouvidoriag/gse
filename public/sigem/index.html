Google Geocoding API — Precisão Cirúrgica (ROOFTOP)

Configuração da API oficial para cravar o pino exatamente no lote/fachada do imóvel.

Por que usar a Google Geocoding API?
• location_type: ROOFTOP: Retorna o número e o telhado exato do imóvel em Duque de Caxias.
• Segurança Total: Sua chave fica armazenada apenas no seu navegador local (localStorage).
• Gratuidade: Toda conta do Google Cloud recebe US$ 200,00/mês grátis (~40.000 requisições).
Necessário ativar a Geocoding API e Places API no Google Cloud Console.
